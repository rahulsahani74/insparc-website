# Project Screenshots

Each subdirectory here corresponds to one project in `src/data/projects.ts`.

## How to add real screenshots

1. Place your screenshots in the matching folder: `public/projects/<slug>/`
2. Name them clearly: `screenshot-1.png`, `screenshot-2.png`, etc.
3. **Before placing screenshots, blur or redact:**
   - API keys and tokens
   - Webhook URLs
   - Client phone numbers and email addresses
   - Any personally identifiable information (PII)
4. Update the `images` array in `src/data/projects.ts` with the correct paths.
5. Preferred format: PNG or WebP, 1200×750px or wider.
