# Insparc Technology Knowledge Base — Sample Document

## 1. Operating Hours & Support
Insparc Technology provides 24/7 automated tier-1 monitoring for all deployed production n8n workflows. Human engineering support is active Monday through Saturday, 9:00 AM to 7:00 PM IST.

## 2. Security Practices
- All client credentials, API tokens, and webhook secrets are stored inside encrypted n8n environment variables or credential vaults.
- We never store customer personal information on third-party servers without explicit data processing agreements.
- Self-hosted instances run on client-isolated VPS containers with HTTPS TLS 1.3 encryption.

## 3. Digital Workflows Refund Policy
Because digital workflow templates include immediate access to proprietary source code JSON and architecture documentation, purchases are non-refundable once downloaded. If a technical bug is identified in a template, our engineering team provides a free patch or replacement within 48 hours.
